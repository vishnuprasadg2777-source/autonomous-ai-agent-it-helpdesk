# PHOENIX IT HELPDESK

### Autonomous AI Agent for IT Helpdesk

> **Understand. Decide. Act. Verify.**

PHOENIX IT HELPDESK is an autonomous Level-1 IT helpdesk system designed to understand user requests, retrieve relevant knowledge, reason over the current IT environment, enforce authorization and risk policies, execute controlled remediation actions, and independently verify the resulting state.

The project is developed as part of **CSS7102 – Mini Project** at **Presidency University** under the official problem statement **PSAIAC_60 – Autonomous AI Agent for IT Helpdesk**.

---

## 1. Project Overview

Traditional IT helpdesk systems primarily depend on ticket routing, predefined workflows, or direct human intervention.

PHOENIX introduces a controlled autonomous-agent approach in which an AI agent can perform suitable Level-1 remediation while maintaining explicit governance boundaries.

Understand → Retrieve → Observe → Reason → Policy → Execute → Verify
